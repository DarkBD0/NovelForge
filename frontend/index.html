新作品默认开启自动文风：章节内容检查通过后，会额外调用模型检查文风，并且最多安全处理一轮；创建后可随时关闭。

模型与运行模式

离线演示使用固定的五章灯塔故事，仅验证生成、确认、修改和完结流程，不代表真实写作质量。

使用真实模型：在启动服务前设置下列环境变量，然后重新运行启动脚本。密钥只留在后端。

NOVELFORGE_MODEL_MODE=http
NOVELFORGE_MODEL_BASE_URL=你的兼容接口基础地址（通常以 /v1 结尾）
NOVELFORGE_MODEL_NAME=模型名称
            NOVELFORGE_MODEL_API_KEY=replace-with-your-private-key（本机免密模型可不填）

接口需支持 Chat Completions 与 JSON 指令输出。远程调用会将该任务的小说上下文发送到你配置的服务；请自行确认服务与费用。

不支持联网的演示模式与真实模型模式不会自动互相回退。完整说明见项目 README。
